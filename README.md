# 📊 Interactive Visualization with Pandas

## 📌 About

This project demonstrates how to build interactive data visualizations using **Pandas** for data manipulation and **Plotly Express** for rich, dynamic charts. It covers bar charts, line charts, scatter plots, and more — rendered interactively inside Jupyter Notebook.

---

## ✨ Features

- 📊 Interactive bar, line, and scatter charts (hover, zoom, filter)
- 🧹 Data cleaning and transformation using Pandas DataFrames
- 📁 Export charts as PNG, SVG, or HTML
- 🔁 Easy to plug in your own dataset

---

## 🛠️ Tech Stack

- Python 3.x
- Pandas
- Plotly Express
- Jupyter Notebook
- NumPy

---

## 🚀 Installation

```bash
git clone https://github.com/your-username/your-repo.git
cd your-repo
pip install pandas plotly notebook
jupyter notebook
```

## 💡 Use Cases

---

## ⚠️ GitHub Note

Plotly charts are **interactive locally** but appear as static images on GitHub.
To view live charts, open in [nbviewer.org](https://nbviewer.org) or run locally.
Static PNG exports are saved in the `/outputs` folder.
